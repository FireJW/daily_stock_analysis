AI-assisted market analysis workflow.

A public portfolio packaging of an A-share analysis automation that connects market data providers, news search, LLM reasoning, scheduled GitHub Actions, and notification channels.

View repository Read README

Data ingestion

Provider adapters cover AkShare, Tushare, Baostock, and YFinance, with runtime configuration through environment variables.

LLM reasoning

Gemini and OpenAI-compatible model paths turn market context into structured dashboards and checklists.

Delivery automation

GitHub Actions can run market reviews, stock analysis, earnings checks, and notification fan-out on schedule.

Workflow shape

The project is easiest to review as an automation pipeline: collect data, enrich it with event context, ask a model for a bounded analysis, then deliver reports through controlled channels.

Safety boundary

This portfolio fork is for learning and workflow evaluation. It is not investment advice, a trading system, or a managed financial service.

Keep real API keys, tokens, private watchlists, account data, and notification endpoints out of commits, screenshots, issue text, workflow logs, and public artifacts.

Original upstream project: ZhuLinsen/daily_stock_analysis. This FireJW repository keeps attribution visible and packages the fork for public portfolio review.
